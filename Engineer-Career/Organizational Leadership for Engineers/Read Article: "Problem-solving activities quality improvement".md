# Read Article: "Problem-solving activities quality improvement"

Problems are normal!

Quality improvement:
* Stage 1: Research phase
  * market research / opinion surveys / product-user groups / customer meetings / six satisfaction elements (product, sales, after-sales, location, time, culture)
  * processing mapping / flow charts / run charts / pareto diagram / fishbone diagram
* Stage 2: Set goals - the vital few
  * SMART (specific, measurable, achievable, relevant, time-bound)
* Stage 3: Decide the means to select the preferred solution
  * brainstorming / nominal group technique / force-field analysis / criteria matrix / bubble-up / circle chart / lateral thinking
* Stage 4: Monitor, implement and review
  * identify risks and develop contingency plans for high probability or high impact risks
  * Six Sigma: understand statistical variation within products and processes; reduces variation to produce more consistent functionality or process output; leading to better processes, more reliable products, lower costs and ultimately happier customers.
  * DMAIC (define opportunity, measure performancem analyze opportunity, improve performance, control performance)
